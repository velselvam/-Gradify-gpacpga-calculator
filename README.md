## 📖 About

Gradify is a smart GPA & CGPA Calculator developed to help Anna University students calculate their semester GPA and overall CGPA quickly and accurately.

It provides a modern user interface with smooth animations, multiple themes, academic analytics, and responsive layouts for both desktop and mobile users.

---

## ✨ Features

- 🎓 GPA Calculator
- 📊 CGPA Calculator
- 📚 Anna University Regulation 2021 Support
- 🚀 Anna University Regulation 2025 Support
- 📈 Semester-wise GPA Tracking
- 🎯 Target CGPA Calculator
- 🌙 Dark & Light Theme
- 🎨 Multiple Theme Colors
- 📱 Mobile Responsive Design
- 🖥 Desktop Mode
- ⚡ Smooth Micro Animations
- 💾 Local Storage Support
- 📊 Beautiful Dashboard
- 🔥 Modern Glassmorphism UI
